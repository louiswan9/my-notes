01. 歡迎來到我的筆記網站：建站與開發規範

本篇重點摘要

  • 本網站採用純靜態 HTML 與 CSS 建置，方便直接部署於 GitHub Pages。
  • 透過根目錄的 AGENTS.md 定義架構與排版規則，確保每次新增筆記都有一致的格式。

為什麼需要 AGENTS.md？

在與 AI 協作開發時，如果沒有事先定義好規則，每次新增頁面都可能出現配色不同、路徑錯誤或忘記更新首頁連結的問題。

新增筆記的標準流程

  1. 在 notes/ 資料夾內建立新檔案（例如 02-topic-name.html）。
  2. 引入上層目錄的 ../style.css 並套用相同的 HTML 結構。
  3. 回到 index.html 補上新筆記的標題、日期與連結卡片。

範例指令

請依照 AGENTS.md 的規範，幫我新增一篇關於「Git 基礎指令」的筆記。
